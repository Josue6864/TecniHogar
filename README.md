

# TecniHogar — Laboratorio 3: Herencia

Aplicación de consola en Java para gestionar servicios técnicos a domicilio. Utiliza herencia y polimorfismo para representar diagnósticos, instalaciones, instalaciones eléctricas certificadas y mantenimientos de aire acondicionado.


## Uso

El menú permite:

- Cotizar y registrar ordenes.
- Registrar cuadrillas.
- Crear jornadas, asignar y retirar ordenes e iniciar la atención.
- Registrar los resultados de las visitas.
- Consultar ordenes, cuadrillas y los tres reportes de gerencia.

Ingrese el número de la opción y presione **Enter**. Seleccione **0** para salir.

Al iniciar se cargan ocho ordenes pendientes y tres cuadrillas, sin ingresos registrados. Utilice punto para los decimales, por ejemplo `2.5`, y escriba los montos sin separadores de miles, por ejemplo `2000`.

Los datos se conservan únicamente en memoria durante la ejecución. Al reiniciar el programa se restablecen los datos iniciales.
